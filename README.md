# Atif Hussain – Portfolio Website

## Files
- `index.html` — Main HTML
- `style.css` — All styles
- `script.js` — Interactivity (dark mode, scroll reveal, navigation, contact form)

## Run Locally
Open `index.html` directly in any modern browser. No build step required.

## Deploy on GitHub Pages (Free Hosting)

1. Create a free GitHub account at https://github.com if you don't have one.
2. Click **New repository** → name it anything (e.g. `portfolio`).
3. Upload all three files: `index.html`, `style.css`, `script.js`.
4. Go to **Settings → Pages**.
5. Under **Branch**, select `main` → `/ (root)` → click **Save**.
6. Your site will be live at: `https://YOUR-USERNAME.github.io/portfolio/`

## Add Your CV Download

Open `index.html` and search for `LinkedIn`. Add your LinkedIn URL to the contact section.
